## 🇺🇦 Українська версія

**Клуб Калідорних Кінокритиків** — це сучасний веб-додаток, створений для кіноком'юніті. Сайт дозволяє переглядати розклад майбутніх кінопоказів, архів переглянутих фільмів, а також пропонувати власні фільми за допомогою інтеграції з базою даних **TMDB (The Movie Database)**.

### ✨ Головні можливості
- **Календар показів**: Перегляд запланованих фільмів з датами, рейтингами та жанрами.
- **Пошук та пропозиції**: Користувачі можуть знайти будь-який фільм через TMDB API та запропонувати його до перегляду.
- **Оцінювання**: Можливість анонімно оцінювати якість показів, атмосферу та зручність платформи.
- **Світла та Темна тема**: Повна підтримка системних налаштувань користувача з плавними переходами.
- **Адаптивний дизайн**: Інтерфейс оптимізовано під будь-які екрани.
- **Адмін-панель**: Захищена панель для додавання нових фільмів у розклад, схвалення пропозицій від користувачів та перегляду статистики.

### 🛠 Технологічний стек
- **Frontend**: HTML5, Vanilla CSS, JavaScript.
- **Backend (Serverless)**: Netlify Functions для безпечного проксіювання запитів до TMDB.
- **База даних**: Firebase Firestore.
- **Аутентифікація**: Firebase Authentication.
- **Зовнішні API**: The Movie Database API.

### 🚀 Посилання на сайт
[Клуб Калідорних Кінокритиків](https://kalidor-club.netlify.app)

## 🇺🇸 English Version

**Kalidor Film Critics Club** is a modern, serverless Single Page Application built for a movie community. The platform allows users to check upcoming movie screenings, browse previously watched films, and suggest new movies via integration with **TMDB (The Movie Database)**.

### ✨ Key Features
- **Screenings Calendar**: View upcoming movie schedules with release years, genres, and TMDB ratings.
- **Movie Suggestions**: Users can search for any movie using the TMDB API and submit it for future viewing.
- **Rating System**: Anonymous community voting on screening atmosphere, movie quality, and platform usability.
- **Dark/Light Mode**: Full support for system-level theme preferences with smooth CSS transitions.
- **Responsive Design**: Mobile-first approach, ensuring perfect layouts across all devices.
- **Admin Dashboard**: A secure control panel to manage the calendar, approve user suggestions, and view detailed voting statistics.

### 🛠 Tech Stack
- **Frontend**: HTML5, Vanilla CSS, JavaScript.
- **Backend (Serverless)**: Netlify Functions to securely proxy TMDB requests and hide API tokens.
- **Database**: Firebase Firestore.
- **Authentication**: Firebase Authentication.
- **External APIs**: The Movie Database API.
